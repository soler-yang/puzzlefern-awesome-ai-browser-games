# Awesome AI Browser Games [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> Curated list of AI browser games: free games you can play in your browser with no download, either built with AI coding agents and models or using AI as part of the gameplay.

AI browser games come in two flavors: games that AI helped write (Claude, GPT, Cursor, Codex and friends), and games where AI is something you play with or against (LLM characters, AI opponents, generated worlds). This list covers both. Every game here is free to try and you can play in your browser, no download. Every link was checked when the list was written; dead ones get removed.

Maintained by [nilveryboring](https://github.com/nilveryboring), who also runs [AIGameShare](https://www.aigameshare.com/games). It is the largest single source here, so the list is deliberately balanced with games from outside it. See [CONTRIBUTING.md](CONTRIBUTING.md) to add yours.

"Built with" lines only state what a source backs up: a model tag on the game's listing, the creator's own credit line, or press coverage. When the source names no model, the entry says so. For [AIGameShare](https://www.aigameshare.com/games) entries, the model comes from the tag on the game's listing page.

## Games Made with AI

### Action

- [A Game About Capybaras Delivering Food](https://capybara-vibejam26.leocoout.dev/) - Take delivery orders as a capybara, shop at a minimart and scooter the stack of items across a city, alone or with friends. Built with Claude Code (Opus 4.7), per [press coverage](https://wccftech.com/ios-developer-made-capybara-game-using-vibe-coding-and-won-25000/) · Three.js. Vibe Jam 2026 gold.
- [BREAKWATER: 3v3 ARAM MOBA](https://www.aigameshare.com/games/breakwater-3v3-moba) - Pick a random hero and fight a 3v3 on one narrow stone dyke while the tide floods and recedes every 90 seconds. Built with Claude Opus 5.5 · HTML5.
- [Driftwake](https://www.aigameshare.com/games/boat-roguelite-driftwake) - Sail expanding 3D seas, pick cannon upgrades, escape a giant Kraken and survive endless enemy fleets. Built with GPT-6 Astra · Three.js.
- [Fanto's Mega-Mart](https://fantos-megamart.vercel.app/) - Race through a haunted grocery store at rocket speed. Vibe Jam 2026 silver; model not stated by the author · see [jam rules](https://vibejam.com/2026/) (90% AI-written code).
- [Ink Warden](https://www.aigameshare.com/games/ink-warden) - Draw brush-stroke glyphs (circle, zigzag, wave, spiral) to cast spells against paper demons and bosses. Built with Claude Fable 5 · HTML5.
- [LAMPLIGHTER](https://www.aigameshare.com/games/lamplighter-pixel-platformer) - Throw a lantern, then blink to it across chasms in a pixel platformer where light turns vines into platforms. Built with Claude Opus 5.5 · HTML5.
- [LANDFALL](https://www.aigameshare.com/games/landfall) - Parachute into a 48-player first-person battle royale with 47 bot opponents, loot, and a shrinking zone. Built with Claude Fable 5 · Three.js.
- [Solmere Souls](https://www.aigameshare.com/games/solmere-souls-pixel-arpg) - Fight through four castle-dungeon chapters as Knight, Archer, Mage or Dragonute in a pixel action RPG. Built with Claude Opus 5.5 · HTML5.

### Racing

- [SaltWind](https://www.aigameshare.com/games/saltwind) - Steer and trim a sail across a 3D sea and chase the fastest seven-gate regatta time. Built with GPT-5 · Three.js.
- [The Great Taxi Assignment](https://great-taxi-assignment.netlify.app/) - Deliver passengers across an 80s-styled neon city in a taxi. Vibe Jam 2025 winner (per [Indie Hackers](https://www.indiehackers.com/post/Uz0wHG4pI3KBOiFhP5YR)); model not stated · Three.js.
- [TINPLATE 3D Kart Racing](https://www.aigameshare.com/games/tinplate-3d-kart-racing) - Drift six wind-up tin-toy racers round a giant 1950s kitchen and release the clockwork key for a boost. Built with Claude Opus 5.5 · HTML5.

### Adventure

- [Echo Abyss](https://www.aigameshare.com/games/echo-abyss) - Ping sonar to see in the dark, hide in sound shadows from blind hunters and dive as deep as you can with one finger. Built with Claude Fable 5 · HTML5.
- [HALDANE-4](https://haldane4.denisbondare.com/) - Survive an ASCII horror game set in the depths of the Southern Ocean. Vibe Jam 2026 "most original" award; model not stated by the author.
- [Lunar Rover](https://www.aigameshare.com/games/lunar-rover) - Drive a rover across a spherical Moon, charge in sunlight and survive the permanent shadow on battery. Built with GPT-5.5 · Three.js.
- [NULL AISLE](https://www.aigameshare.com/games/null-aisle) - Explore an infinite data-center maze through failing VHS video and procedural spatial audio. Built with GPT-5 · Three.js.

### Puzzle & Logic

- [Hashi — Puzzle Fern](https://puzzlefern.com/hashi/) - Connect numbered islands with bridges across 12 fixed, original puzzles with unique solutions, undo and browser-local saves. Built with AI assistance (model not stated) · HTML, CSS and JavaScript.
- [Klotski](https://www.aigameshare.com/games/klotski) - Slide the blocks of the classic Huarong Dao puzzle through 36 levels with hints and drag controls. Built with GPT-5.5 · HTML5.
- [Nonogram](https://www.aigameshare.com/games/nonogram) - Fill grids from row and column clues to reveal pixel pictures, with 370+ puzzles that are solvable by logic alone. Built with Claude Fable 5.1 · HTML5.
- [Shadow Opera](https://www.aigameshare.com/games/shadow-opera) - Rotate carvings and move a lantern so load-bearing shadows carry you across each act of a shadow-puppet puzzle. Built with Claude Fable 5 · Three.js.
- [Sokoban](https://www.aigameshare.com/games/sokoban) - Push crates onto goals across 123 levels, each checked by a solver, with undo and optimal-push hints. Built with Claude Fable 5.1 · PixiJS.
- [WenWare](https://wen-ware.com/) - Guess where and when a historical scene took place in a GeoGuessr-style game. Vibe Jam 2026 bronze; model not stated by the author.

### Card & Board

- [Classic Solitaire](https://www.aigameshare.com/games/classic-solitaire) - Play Klondike with draw 1 or draw 3, undo, hints and daily deals. Built with GPT-5.5 · HTML5.
- [Fanorona](https://www.aigameshare.com/games/fanorona-game) - Use approach, withdrawal and multi-capture moves against an Easy, Medium or Advanced AI. Built with GPT-5 · HTML5.

### Arcade

- [CLOUDWALK](https://www.aigameshare.com/games/cloudwalk-3d-balance-ball) - Roll a ball along plank walks above a sea of clouds, swapping between paper, wood and stone forms across eight stages. Built with Claude Opus 5.5 · HTML5.
- [Geobeat](https://dmnshd.gg/games/geobeat) - Dodge the beat in a minimal WebXR arcade game, in AR or on screen, and chase high scores. Vibe Jam 2026 entry ([write-up](https://dmnshd.gg/blog/vibe-jam-2026-geobeat)); model not stated · Immersive Web SDK.
- [HANABI 3D Pinball](https://www.aigameshare.com/games/hanabi-3d-pinball) - Shoot ramps and orbits on a festival-night table to load fireworks, then launch them all from the tower. Built with Claude Opus 5.5 · HTML5.
- [KELIR](https://www.aigameshare.com/games/kelir) - Steer through a shadow-puppet survivors arena while your weapons fire themselves, ending in three demon-king fights. Built with Claude Fable 5.1 · PixiJS.
- [NORDWAND](https://www.aigameshare.com/games/nordwand-3d-wingsuit-flying) - Leap off a summit, skim the rock for proximity score, thread gates and land on the cross. Built with Claude Fable 5.1 · HTML5.
- [Tornado Chase 3D](https://www.aigameshare.com/games/tornado-chase-3d) - Fly a camera drone to photograph a moving tornado with three shots, then sell the footage and upgrade. Built with GPT-6 Sol · HTML5.
- [Vibeware](https://vibeware.vercel.app/) - Play as a scraping bot through WarioWare-style microgames with an annoying soundtrack, and add your own. Vibe Jam 2025 winner (per [Indie Hackers](https://www.indiehackers.com/post/Uz0wHG4pI3KBOiFhP5YR)); model not stated · React.

### Simulation & Strategy

- [fly.pieter.com](https://fly.pieter.com/) - Pick a plane and fly in a shared multiplayer flight sim. Built with Cursor · Three.js (credit line on the page: "100% made with AI").
- [MERIDIAN](https://www.aigameshare.com/games/meridian) - Sail and trade across a spherical Earth with 114 ports while following four treasure expeditions. Built with GPT-6 Astra · HTML5.
- [Mintfall](https://www.aigameshare.com/games/coin-pusher-roguelite-mintfall) - Push coins in a 3D coin pusher where combos, relics and six rounds shape your coin clip. Built with GPT-6 Astra · WebGL.
- [Tabletop Empires](https://www.aigameshare.com/games/tabletop-empires) - Found cities and lead painted miniature armies through eight eras of a turn-based 4X on a 3D tabletop. Built with Claude Opus 5.5 · HTML5.
- [Tidewell](https://www.aigameshare.com/games/tidewell) - Build and tend a cozy 3D aquarium of procedural fish, breed rare colors and sit back to watch. Built with Claude Opus 4.8 · Three.js.
- [Vector Tango](https://www.vector-tango.com/) - Guide planes as an air traffic controller in a 3D simulator. Vibe Jam 2025 winner (per [Indie Hackers](https://www.indiehackers.com/post/Uz0wHG4pI3KBOiFhP5YR)); model not stated · Three.js.

### Sports

- [BRUTAL FC](https://www.aigameshare.com/games/brutal-fc) - Play one-thumb 3v3 street football with tap passes, flick shots and a heat multiplier that one turnover wipes. Built with Claude Fable 5 · Three.js.
- [LITTLEBURY 3D Mini Golf](https://www.aigameshare.com/games/littlebury-3d-mini-golf) - Putt 18 holes through an English model village with windmills, a steam train and a drawbridge. Built with Claude Opus 5.5 · HTML5.

## Games with AI in the Gameplay

### AI Characters & Story

- [AI Dungeon](https://play.aidungeon.com/) - Type what you do and the AI narrates what happens in text adventures and community scenarios. Not a game built with AI; AI runs the story.
- [AI Town](https://github.com/a16z-infra/ai-town) - Deploy and customize a virtual town where AI characters live, chat and socialize. Open-source starter kit, MIT license.
- [Hidden Door](https://www.hiddendoor.co/) - Create characters and play out stories where you can do anything, in roleplay that mixes with fan fiction.
- [Infinite Craft](https://neal.fun/infinite-craft/) - Combine two elements to discover a new one, with an AI model deciding what any pair makes.
- [Lakera Agent Breaker](https://play.lakera.ai/agent-breaker) - Attack ten AI apps (a cycling coach, a legal assistant, a code reviewer) with prompt injections to steal data or secrets, scored 0 to 100 per attempt. Opens at the page that replaced the original Gandalf game.
- [Perchance AI Text Adventure](https://perchance.org/ai-text-adventure) - Play a free text adventure with no sign-up and no limits, an AI Dungeon alternative.
- [Tensor Trust](https://tensortrust.ai/) - Climb a leaderboard by fooling AI language models with prompt injection attacks, and write defenses against others.

### AI Opponents

- [Chess.com Computer](https://www.chess.com/play/computer) - Play chess against bots at every skill level, from coach bots to a roster of character bots.
- [Leela Chess Zero](https://lczero.org/play/) - Play against an open-source neural network chess engine.
- [Lichess](https://lichess.org/) - Play chess against the computer, friends or random opponents with no registration.
- [Quick, Draw!](https://quickdraw.withgoogle.com/) - Draw doodles and watch a neural network try to recognize them, and help teach it by playing.
- [Reversi](https://www.aigameshare.com/games/reversi) - Play Othello against an Easy, Medium or Hard AI with legal move previews, undo and hints. Built with GPT-5 · HTML5.
- [Which Face Is Real?](https://www.whichfaceisreal.com/) - Click the real person out of two faces, where the other is computer-generated. University of Washington project.
- [Xiangqi Duel](https://www.aigameshare.com/games/xiangqi-duel) - Play Red against a stronger Xiangqi AI on a Chinese chess board with legal move highlights. Built with GPT-5.5 · HTML5.

- [AIGameShare](https://www.aigameshare.com/ai-browser-games) - 470+ free AI browser games, each labelled with the model that built it, with leaderboards, cloud saves and weekly trending picks.
- [itch.io: AI-generated](https://itch.io/games/tag-ai-generated) - Games on itch.io tagged as AI-generated.
- [itch.io: LLM](https://itch.io/games/tag-llm) - Games on itch.io tagged llm, including browser-playable ones where a language model runs the game.
- [itch.io: vibe-coding](https://itch.io/games/tag-vibe-coding) - Games on itch.io tagged vibe-coding.
- [Vibe Jam](https://vibejam.com/2026/) - Annual jam run by Pieter Levels (levelsio) for browser games with at least 90% AI-written code and no login. 2025 and 2026 entries are archived on the site.

## Tools for Making AI Browser Games

- [AIGameShare MCP server](https://www.aigameshare.com/developers) - Hosted MCP server that lets Claude Code, Codex, Cursor and other agents publish an HTML5 game with a play page, leaderboards and cloud saves.
- [Blender MCP](https://github.com/ahujasid/mcp-for-blender) - Community plugin to control Blender with an LLM, useful for generating 3D assets and scenes.
- [Bolt.new](https://bolt.new/) - Prompt-to-app builder; sponsor of the Vibe Jam.
- [Claude Code](https://code.claude.com/docs/en/overview) - Anthropic's terminal coding agent.
- [Codex CLI](https://github.com/openai/codex) - OpenAI's open-source coding agent for the terminal.
- [Cursor](https://cursor.com/) - AI code editor; sponsor of the Vibe Jam and used for fly.pieter.com.
- [Godot MCP](https://github.com/Coding-Solo/godot-mcp) - MCP server that launches the Godot editor, runs projects and captures debug output.
- [PlayCanvas](https://playcanvas.com/) - Web-first game engine and editor.
- [Phaser](https://github.com/phaserjs/phaser) - 2D HTML5 game framework.
- [React Three Fiber](https://github.com/pmndrs/react-three-fiber) - React renderer for Three.js.
- [Rosebud AI](https://rosebud.ai/) - Describe a game idea or pick a template, then build and deploy it.
- [Three.js](https://threejs.org/) - The 3D library most AI-built browser games use.
- [Unity MCP](https://github.com/CoplayDev/unity-mcp) - Bridge between AI assistants and the Unity Editor to manage assets, scenes and scripts.
- [WebLLM](https://github.com/mlc-ai/web-llm) - In-browser LLM inference engine, for games where the model runs on the player's device.
